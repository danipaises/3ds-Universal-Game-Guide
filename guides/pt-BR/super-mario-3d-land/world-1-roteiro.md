# World 1 > roteiro e checklist

Fases deste mundo: 1-1, 1-2, 1-3, 1-4, 1-Castle.

Roteiro de coleta: conclua cada fase, volte às medalhas faltantes e alcance o topo do Goal Pole quando houver bandeira. Consulte os ícones do mapa para separar fase concluída, medalhas e bandeira. Se uma entrada exige medalhas, revisite uma fase curta que você já conhece.

Faça a primeira visita pelo caminho seguro e deixe saltos de coleta arriscados para uma segunda tentativa com item reserva. Esta página é uma lista de fases; as posições individuais das medalhas deste mundo ainda estão pendentes.
